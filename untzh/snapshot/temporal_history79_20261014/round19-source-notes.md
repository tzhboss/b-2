# 第十九轮：同一历史事实真值固定的配对界限

本轮保持原随机40条，读取既存40×10094评分缓存与候选映射，不调用模型。逐条重建前后原filtered排名，全部与原缓存一致。新公式对同一日期候选固定一个真值：错误竞争净增D=sum(false(e)×(after权重−before权重))，严格超过gold权重1、并列0.5、不超过/原候选不存在0。已知真答案贡献0；已知假答案按实际权重差贡献；未知项下界取min(差,0)，上界取max(差,0)。逐条给出达到端点的固定真值赋值，以确认是该标签条件下的候选逐项界限。人口层面存在共享事实约束，未宣称所有查询界限可同时达到。

此前分别估计前后错误竞争总数的界限有效但偏松：对同一个一直排在gold前面的候选，其真假不能在前后任意改变，应抵消。

组织时间反证口径仍只有S38：样本错误漂移下限1/40=2.5%。如果把问题明确限定为“当日新行动”，并接受人物身份与同日gold映射，则S33也成立，下限2/40=5%。这是新增语义条件下的逻辑下限，不是把语义未定条目自动标错，也不是总体错误率点估计。两种口径分开保存，未知不计合理。

新单侧95%有限总体超几何下界分别由至少1/至少2条确认病例反演，数值见paired-population-bounds-round19.json。原round12下界资产不改写。这些统计界限不能解决报道日/行为日含义，也不是跨模型数据集结论。
