# 下一假设：保护位移与新增跨新旧事实的查询空间协调

依据089–091：风险路由可增强TRAIN保护，却不能稳定提高整体学新—保旧效用；uniform排名损失也仍是取舍。既有060/063投影只针对批次总学习梯度或其每实体分量，不能据其结果排除保护所有已见正例分数的参数空间限制。

拟定下一实验，尚未编码/启动，不称原创或已有收益：

1. 固定088 seed29第二增量prefix/Adam/tape/cohort，保护使用fullabsolute，rho .1，旧E/R冻结。每个新实体收集涉及一个旧端点的全部新TRAIN方向事实。其正例分数对该新行线性，固定旧端点与关系形成查询向量；缓存这些向量张成空间的正交基。人工逆边保留各自关系，不错误替换R。
2. 同当前状态计算host-only Adam提案和joint-gradient Adam提案，二者之差定义附加保护位移。保护附加位移投影到该新实体已见查询空间的正交补。真实host optimizer只记录host学习梯度，避免保护动量污染后续host路径；此权限改变也需控制。
3. 新臂至少有host-state-only未投影、正交补投影、未投影但按本状态投影后的位移norm缩放。与090joint fullabsolute历史控制相比，前者隔离优化器状态改变，后两者区分方向选择与单纯降低强度。所有新臂同采样预算，记录实际位移norm和projection准备费用。
4. 基本检查实际FP32追加位移对这些TRAIN正例分数的变化，披露舍入误差。数学线性条件仅涉及旧端点固定的已见跨端事实；双新端事实存在交叉项，VALID未知事实不在约束集合，不保证其分数或排名。仍统一评价三新方向、旧MRR和掉榜。
5. 若null空间太小或未投影缩幅控制同样有效，如实退出该机制解释；不靠更多网络保持故事。计算若实质昂贵也计入方法成本，缓存只在对应TRAIN与冻结模型不变时复用。

该思路与持续学习中的正交子空间方法相关，文献新颖性与近邻尚待核对；即使有开发收益，也不能直接作为原创或最终投稿方法。下一实验新目录统一/data/lc/untzh，无硬超时、独审或SHA门槛。
