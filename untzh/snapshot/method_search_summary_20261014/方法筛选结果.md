# 063–078：找到一个小幅联合收益的候选

主候选是**分阶段、双信号梯度混合保护**：先普通学习10轮，后10轮将绝对候选压分与新候选概率质量保护按各自校准后的梯度各混合一半。固定seed17/DistMult200/FB-CKGE0→1，旧实体和关系冻结。它没有额外学习器或扩大可训练模型参数。

截至078实际完成16轮、247个训练/校准/对照配置，其中181个训练配置、66个无需重训的校准配置，另160个真实37步TRAIN干预分支。247不是247种独立算法。所有新产物在/data/lc/untzh；候选来源normalized77_20261014/models/cohort_blend0.5/epoch-20.pt。逐轮完整结果见各evaluation/metrics.json，全部配置及费用索引见“全部配置索引.md”。没有TEST、独立CPU审计、SHA门槛、归档、固定耗时终止或跨seed确认。

## 实际方法

每步固定抽32个旧TRAIN合格答案，每个答案使用128个固定合法新候选，候选身份及TRAIN过滤规则复用058缓存。保护查询q及旧池分数可以缓存，因为oldE和R冻结。

1. absolute信号为新增候选分数的softplus均值，提供普遍的竞争压分。
2. mass信号估计新增候选的exp分数总量，再与teacher旧候选池的exp分数总量比较，损失为log(1+估计新质量/旧质量)。旧池过滤其他TRAIN正确答案、保留当前gold；新池排除该query已知TRAIN新答案。128抽样exp总量按合法池大小放大，其log并非无偏估计。
3. 初态8个TRAIN batch分别将两个信号的RMS新行梯度校准到学习梯度的.1；训练每步各自再限幅.1，最后各取一半相加，用原Adam更新新行。合成保护norm不超过学习norm的.1，不是实际Adam位移或排名安全保证。

没有采用风险学习器路由：当前证据中，它们的预测优势未稳定变成保护收益。事前风险识别的058–061结果仍可作为诊断证据，但不能把本候选说成已经实现了更优的学习型风险分配。

## 适用边界与统计不确定性

开启时点确实重要。078固定混合份额不变，改到第5轮开始保护：新MRR .149051682、旧VALID4、旧TRAIN4129、三个方向保持比.980316/.988760/1.000687，属于更强保旧、稍弱学新的另一取舍；从初态就保护的旧→新比.973355，未通过原开发筛选。第10轮方案不能外推为任何开启时点都有效。

Raw口径并非全面支配。相对均匀保护，旧TRAIN raw MRR .375302709→.375290524，旧VALID raw MRR .151674195→.151657090，新头→旧答案raw MRR .239368113→.239128057，均略降。Raw旧TRAIN掉榜786→785，旧VALID仍4，新总体raw MRR .128851075→.128911968。必须同时保留这类次要退化，不能宣称所有指标或历史合同全部通过。

新VALID filtered MRR配对差为+.000598468。3000次(h,r)查询簇bootstrap的描述性95%区间为[-.000121515,.001737583]，包含0；1024答案中353改善、468不变、203下降。这个区间是在247次开发比较之后计算，没有纠正选优偏倚，也没有处理共享实体的全部跨query依赖。它不证明统计显著性或未见数据泛化。

这些信号、分层采样、阶段训练及梯度组合都有既有思想来源。本轮没有完成文献新颖性证明，不能把“找到了可测试的候选”写成“已完成论文原创方法/投稿证据”。

## 多方向探索得出的取舍

| 方向 | 实际结果与判断 |
|---|---|
| 相对gold/边界/capacity/预测margin | 有组总体新MRR提高，但关键旧头→新答案损失或保护不足 |
| 风险route/梯度冲突启发式route | 没有超过均匀保护的联合取舍 |
| 真实短分支收益学习器 | 160真实分支；留出收益相关性弱，4路由组均未筛中 |
| TRAIN语义排除/降权 | 学新有所改善，旧TRAIN保护较弱 |
| 实体/坐标投影与postAdam | 减轻部分学新损失，但旧TRAIN保护往往变弱 |
| 对比学习/完整softmax及混合 | 学新潜力明显，同时旧竞争损伤大；匹配none控制全部保留 |
| 全局/条件尺度及偏置校准 | 整体或方向损失仍存在；漂亮VALID组补TRAIN后旧损伤更多 |
| 新实体head/tail角色拆分 | 容量翻倍，没有更好的整体取舍 |
| 很小旧E/R学习率+回放/蒸馏 | 未通过开发筛选；旧参数移动和新学习损失仍有取舍 |
| TRAIN已知正例负样本过滤 | 3721400负抽样中已知正例为0，不能解释当前问题 |
| 全保护池/大batch/query/关系分层 | 更大batch不免费改善；关系分层+轻微学习补偿是备选，小幅收益且时点敏感 |
| 分数尺度归一化 | 总体新MRR提高组常伴关键方向损失；没有优于主候选 |
| absolute与概率质量保护混合 | 当前主候选，filtered三方向/旧MRR/旧掉榜同时改善，但增益小，统计未确认 |

备选075关系分层+weight1.1/rho.15在第10轮之后：新MRR .151030814、旧VALID4、旧TRAIN4428；优于原uniform的总体取舍，但匹配同weight/rho的globaluniform旧TRAIN4183、更强保护、关键方向损失也更大。076第0/5轮开启时关键方向未通过，不能称稳健普适方案。

## 效率与结果保存

主候选后10轮/370步实际训练1.876秒，历史均匀保护1.507秒，异时记录约1.25倍，非独立基准或完整部署费用。两种候选共享32×128采样评分，但混合有两次梯度计算。前10轮学习、teacher旧logZ和cohort缓存、初态校准费用仍需支付；077本轮57.517秒还含12个配置的筛选、完整TRAIN评价及准备，不能全算某一个方法的部署成本或省略共享成本。

所有实验以prepare/train/evaluate/summarize流程执行。063–078主程序均结束，原会话已退出，无待poll。072原12组保存后KL计算图错误保留日志，修成重新组装当前E，仅接续3个未训练KL组；旧12组未重训。064补TRAIN完成后rank函数把status留在evaluate，终态以main/extra日志和完整metrics为据；没有把旧字段误判为仍在运行。072记录total_seconds为接续墙时，完整训练合计另外列出，不能直接当本轮总时间。汇总脚本修正兼容不同cost字段类型，不触碰模型或重新评分。
