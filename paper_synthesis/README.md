# Paper Synthesis Package

This directory is a derived, paper-oriented view of audited experiment outputs.

- SYNTHESIS.md: current paper-level claim boundaries.
- tables/evidence_matrix.csv: claim-to-experiment evidence mapping.
- tables/limitations_and_exclusions.csv: results that must be qualified or excluded.
- tables/table1_* through table7_*: paper-ready numerical source tables.
- figures/fig1_* through fig4_*: automatically generated mechanism/deployment figures.
- scripts/build_paper_package.py: deterministic builder from results/.

Do not edit numerical tables or figures manually; regenerate from audited result files.
