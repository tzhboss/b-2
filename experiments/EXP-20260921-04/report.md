# Experiment Report — EXP-20260921-04

## Main Result

The central target-reference coupling survives nonlinear feature access.

Across MSP and IEMOCAP, increasing between-speaker target structure makes Relative progressively
less favorable than Absolute for Arousal and Dominance under both linear Ridge and a fixed
quadratic Ridge model.

The effect magnitude is nearly unchanged in MSP and remains directionally and statistically stable
in IEMOCAP.

## Interpretation

This mechanism is more robust than many class-level categorical-emotion effects observed earlier.
The key result is not that one representation always wins, but that changing the target reference
frame systematically changes which representation is useful.
