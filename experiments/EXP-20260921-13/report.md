# Experiment Report — EXP-20260921-13

EXP-20260921-13 cannot be used as confirmatory evidence because the same five deterministic
leave-one-session-out folds were repeated under three seed labels and incorrectly treated as
independent inferential units.

Descriptively, all four Arousal/Dominance mean slopes remain negative, but only 2-3 of the five
sessions show a negative slope in each model-target cell. Session heterogeneity is therefore
substantial.

A corrected post-hoc session-level sensitivity table is generated separately and should be reported
as a limitation/sensitivity result, not as a preregistered confirmation.
