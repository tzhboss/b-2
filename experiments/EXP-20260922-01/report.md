# Experiment Report — EXP-20260922-01

The target-reference mechanism remains strong when all six validated interpretable prosodic attributes are combined into one representation.

Across both Linear and Quadratic Ridge, Relative-minus-Absolute slopes are strongly negative for Arousal and Dominance, with speaker-cluster 95% confidence intervals entirely below zero. At the pure within-speaker endpoint (lambda=0), Relative significantly outperforms Absolute in all four model-target cells.

At the opposite endpoint (lambda=1), Hybrid significantly outperforms Relative in all four cells. This shows that the full interpretable representation reproduces the same decomposition observed in the earlier targeted analyses: speaker-relative information is useful for within-speaker variation, while speaker-center information becomes useful as between-speaker target structure increases.

The combined representation therefore provides a paper-ready, interpretable confirmation that the effect is not driven by one isolated prosodic attribute or one classifier family.

Decision: pass.
