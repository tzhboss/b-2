# Experiment Report — EXP-20260921-15

Speaker-cluster inference strengthens the main target-reference claim on MSP.

All four confirmatory Arousal/Dominance slopes remain strongly negative after treating speaker,
rather than fold or seed, as the independent sampling unit.

IEMOCAP retains the same negative direction under both Linear and Quadratic Ridge, but its
speaker-cluster confidence intervals cross zero because the corpus contains only 10 speakers.
The within-speaker endpoint Relative advantage remains clearly positive.

This experiment supersedes fold/seed bootstrap as the preferred uncertainty analysis for the main
Pitch+Rate mechanism result.
