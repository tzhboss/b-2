# Submission Readiness Audit

## Scientific core

Ready:
- Main mechanism has a preregistered, semantically matched cross-corpus confirmation.
- Main effect survives linear and quadratic model families.
- Mechanism has a direct speaker-center permutation intervention.
- Deployment reference estimation has a corrected fixed-pool experiment.
- Negative and invalid experiments are preserved and explicitly scoped.

## Novelty boundary

Must be explicit:
- Speaker normalization itself is old.
- Relative prosody for arousal is old (Bone et al., 2012 is particularly close).
- Small enrollment / personalization is also established in prior work.

Candidate novelty:
- Explicit representation-reference / target-reference matching formulation.
- Controlled intervention on target between-speaker structure.
- Demonstration that normalization preference changes continuously under that intervention.
- Correct-speaker center permutation that isolates center identity utility.

## Evidence that should stay out of the strongest headline

- IEMOCAP loudness.
- Strong universal speaker-identity suppression.
- Monotonic K-shot recovery on IEMOCAP.
- Strict session-disjoint IEMOCAP replication.
- Universal Valence mechanism.
- Universal Relative advantage after WavLM.

## Remaining work before submission

1. Full bibliography pass using venue-authoritative records.
2. Decide target venue and fit manuscript length/format.
3. Add dataset/preprocessing table with exact sample counts and label construction.
4. Add statistical protocol subsection defining bootstrap units and speaker balancing.
5. Convert figures to venue-compliant vector/PDF format if required.
6. Add reproducibility appendix with experiment IDs, commits, and validity decisions.
7. Run a language/claim audit after final edits.
