# 可比性核查

统一排名指标与统一学习任务是两件事。共同评价可定义为：全候选实体、无真值过滤、strict >排名、k10；记录原Top10正确答案的掉出数/比例，并同时记录新知识的学习成功与成本。不同的初始模型、候选集合、事实队列和优化信息不能借统一指标变成公平的直接算法比较。

| 方法 | 共用raw排名指标 | 直接接入当前DistMult/ComplEx单次编辑主表 | 本轮处理 |
|---|---|---|---|
| Direct/Rank/StrictNull/Ridge | 是 | 是 | 相同400请求；无新调参 |
| Support TRAIN | 是 | 是，明确TRAIN适配 | 复用已审向量 |
| Support all-split | 是 | 可以重建，但额外标签须声明 | 两种目标处理约定都保留 |
| TRUE-only QP+Rank | 是 | 是 | 复用036消融 |
| TRUE+Prediction QP+Rank | 是 | 是 | 复用034已审更新 |
| IncDE/LKGE | 是，须重新生成无过滤分数 | 不能作为原方法直接插入 | 原生多快照/TransE式模型，先前filtered排名表不混入主表 |
| FastKGE/STARK | 是，须显式加入当前新增候选 | 不能作为原方法直接插入 | 旧候选内零损伤不足以证明当前全候选安全 |
| KGEditor | 是，可用其实体logits计算 | 不能直接插入 | 语言模型架构、编辑器训练及EDIT/ADD任务不同；本QP需要候选尾线性评分 |
| SAGE | 原理上可以 | 不能直接插入 | 保留原完整性FAIL，不能用未通过的产物作正式基线 |

若要将持续学习方法也放入真正相同的编辑任务，需固定初始模型、数据ID与新事实输入，保留其蒸馏/LoRA/重构等目标的有效实现，并匹配旧数据访问和成本。换成DistMult或单条编辑后的实现必须标“适配”，重新训练并验证方法行为；它不是此前作者原任务复现。若保留它们的原始模型，应作为独立模型面板，不能把模型差异解释为优化算法优劣。

当前请求的直接可执行部分为Rank系列与QP+Rank的同400比较。未声称所有持续/LM方法已完成统一编辑任务训练，也未用各自MRR/filtered掉出率冒充统一raw SafeSucc。
