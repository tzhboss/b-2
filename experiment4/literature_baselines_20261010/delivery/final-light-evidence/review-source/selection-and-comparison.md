# 本轮文献复现范围与可比较性

主执行目录 /data/lc/tzh/experiment4/literature_baselines_20261010。该文件为事前范围/源码核查说明，训练、下载与审计的实际状态以各 experiments/KGE-LIT-00*/experiment.yaml、进程终端收据和审计文件为准。

| 文献/方法 | 对当前方向的作用 | 本轮范围 | 比较边界 |
|---|---|---|---|
| KGEditor / Editing Language Model-based KGE | 直接编辑相关强基线；编辑分支、局部性与快速更新均已存在 | 作者 PT-KGE 检查点与两个 EDIT 数据集；准备原生编辑器训练和逐例指标 | PLM-KGE，不与 DistMult/ComplEx 的 Top10 SafeSucc 混为同一协议；验证/测试消费关系待源码审计 |
| IncDE, AAAI2024 | 增量蒸馏与遗忘控制基线 | 作者四个主要划分 ENTITY/RELATION/FACT/HYBRID，五快照完整训练 | 历史查询快照候选集合/过滤；单种子3407，不等同论文多种子均值 |
| FastKGE, IJCAI2024 | 高效增量低秩更新；效率与局部更新声称的前作 | FB_CKGE 五快照完整作者配置 | 与 STARK 原始划分逐字节一致；和 targeted editing 不同 |
| STARK, WWW2026 | 结构感知与自适应表示的直接前作 | 公开代码 FB_CKGE 五快照完整训练 | 原版读取距离列而不是 PageRank；完整论文未获取，不称完整论文公式复现 |
| SAGE, arXiv2508.11347 | 表示维度扩展/动态 KGE 的强方法参照 | V1.0 作者默认 FACT 五快照、180/210/250/270/290维 | 与 IncDE FACT 三元组集合一致但排列不同；源码预设维数，无已确认动态蒸馏实现，不把源代码结果包装成全部论文方法 |
| Pons et al., arXiv2604.19401 | 旧查询表示/旧正例分数不变仍可能因新增竞争实体而遗忘 | 读取作者源码，固定同检查点候选扩张诊断（KGE-LIT-005） | 独立实现的 Pons 动机评估诊断，不声称作者完整八数据集复现 |
| AlphaEdit/AlphaEdit+ | 投影、保留子空间和冲突处理的机制前作 | 主论文公式与固定版本作者代码审查 | 原生 LLM 编辑任务不同；本轮不下载大模型做跨任务数字比较 |
| LKGE | 持续 KGE 经典基线 | 已准备原版与独立 valid.txt 的分割修订副本 | 原版用 test.txt 选检查点；未运行不列实测数值，不把修订版标成完全原版 |
| KBS2026 DOI10.1016/j.knosys.2026.116976 | 结构局部性、关系感知 PLM-KGE 编辑前作 | 元数据与可获得出版摘要/引言核查 | 未获得完整方法和作者代码，明确列未复现/方法细节未解决 |

所有方法保持其完整训练上限及原生早停。下载失败与工程失败原样保留；不以 CPU预检查或导入成功作为完成复现。结果至少核查终端成功、快照/检查点/逐查询覆盖、数据/源码哈希与独立指标复算后才能提升。

两个确认可对照的组是 FastKGE/STARK FB_CKGE（字节相同），以及 IncDE/SAGE FACT（三元组多重集合相同；排序和种子/维数/训练策略不同）。仍需确认候选/过滤/tie定义。其余分组及编辑任务分开列，不形成混合 SOTA 表。

现有 QP 的有限固定列约束、可行性审查与 Rank 回退不构成已确认创新；共享 head/tail 影响及竞争实体必须额外评估。该轮复现不自动提供论文投稿 GO。
