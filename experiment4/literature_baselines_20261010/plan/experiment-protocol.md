Record actual commit, original/compatibility diff and input hashes. Hold out official test for declared author-protocol final evaluation, never tune on it. Report native paper metrics and measured cost; add damage metrics only as explicitly declared adaptations. Full native run rather than smoke-only is needed for a completed reproduction.
