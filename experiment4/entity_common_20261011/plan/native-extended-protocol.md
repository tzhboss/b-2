# IncDE 与 SAGE 的共同新增实体适配

固定同一 FB_CKGE 0→1、三种子17/29/43、完整11258候选与首批查询顺序、相同旧/新各1024VALID及其等权raw MRR选模。200epoch、batch1024、10 negatives、2400秒含维数映射训练预算。作者原生训练器、loss与负采样保留，统一两快照 TRAIN namespace替代读取所有split的原加载器。无需另读TEST构造权重或映射。TEST只在选定检查点后进入统一评价。本批不是原论文数据协议/指标复现。

IncDE使用审计的共同TransE200旧检查点及相同有效扩展新实体初始化。保留原生两阶段、可学习mask权重、逐batch蒸馏与新行buffer刷新。原加载器try读排序文件后被train.txt覆盖，故依实际源码保持原TRAIN顺序；不声称层级排序机制已按论文意图运行。节点betweenness采用NetworkX全源Brandes子集并行求和，每个源/目标完整覆盖，没有k近似；五个合成图与原串行函数核对。分块求和末位浮点舍入限度明示。degree文件按原TRAIN图生成；原训练器实际degree分支复用betweenness值，保留原生行为。

SAGE从同seed审计的TransE180底座开始，用原生evaluate_on_training_data仅从旧TRAIN采样，再执行原main.py的train_mapping_matrix方法（AST提取精确函数体，避开路径删除、TEST与主驱动）。映射180→30后拼接成210维，再原生switch_snapshot/MAE/importance regularization增量训练。固定new_dim_epoch_num1、num_samples_for_retrain1000，原采样及覆盖逻辑保留。原easy分支Softmax对象构造取.dim的实际行为保留，不默默修成另一采样器。映射数据与成本单独存证。原SAGE生产记录的metadata完整性FAIL仍保留，当前科学源码逐文件绑定copied manifest；不能把新适配审计通过改写为原运行完整性通过。

维数变化使旧评分可能在增量学习前已变动，因此SAGE主before由原180维底座评分；同池辅助before由映射后210维扩展初态评分。两者不混淆。原生predict与导出实体/关系表评分需检查一致；检查点保存实际有效状态，含IncDE两阶段buffer。审计64个完整候选行及全查询ID/指标聚合，核验SAGE映射支持均属于旧TRAIN；只提升通过审计的轻量结果。首批队列完成后再分配GPU，避免两个调度器争用。全比较仍包含KGEditor及Rank/QP，不以本批结束替代整个目标。
